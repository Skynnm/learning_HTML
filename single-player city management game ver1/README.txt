城池经营 · 单机游戏 Demo
========================

这是一个可直接运行的单机「城池经营」游戏，纯 HTML + CSS + JavaScript 实现，
无需安装任何软件或联网，双击即可游玩。

如何开始
--------
1. 双击本文件夹中的 index.html 文件（会用默认浏览器打开）。
2. 点击「开始游戏」即可游玩。

玩法说明
--------
- 你是一座小城的主人，通过点击右侧「建造」面板中的建筑，再点击地图格子来建造。
- 点击「下一回合」推进游戏；每回合产出资源、人口增减，并可能触发随机事件。
- 需要拆除建筑时，点击「拆除」按钮进入拆除模式，再点击地图上的建筑。

资源与建筑
----------
- 金币：建造与军费，靠集市产出 + 人口税收。
- 粮食：养活人口，靠农田产出；粮食不足会闹饥荒、饿死人口。
- 木材 / 石料：分别靠伐木场 / 采石场产出。
- 人口：需要民居提供住房，民心高且粮食充足时增长。
- 兵营 / 城墙：提供防御，抵御匪患；兵营有金币和粮食维护费。

胜利与失败
----------
- 胜利：人口 ≥ 50 后建造「宫殿」（200 石料 + 500 金币）。
- 失败：人口归零；或民心连续过低（≤5）引发民众暴动。

提示
----
- 前期优先建伐木场和采石场，保证木材、石料来源。
- 扩建民居并多种农田，让人口持续增长。
- 记得修建兵营和城墙，匪患强度会随回合数提高。
